# 🌐 Innovatech Solutions

A modern, fully responsive website built with a focus on **clean design, smooth animations, and better user experience**.  
The project includes multiple sections such as Navbar, Hero, Key Features, Success Stories, Pricing, and Footer — all structured and styled carefully for responsiveness and interactivity.

## 🛠 Tools Used

- **HTML5** – Semantic and structured markup
- **CSS3** – Styling, layout, responsiveness, animations
- **JavaScript (ES6)** – Interactivity and effects
- **Git & GitHub** – Version control and collaboration

## 🛠️ BulkNest Client – Local Setup Instructions

- **Clone the repository and install dependencies:**

  ```bash
  git clone https://github.com/wdNaimur/Innovatech-Solutions.git
  cd Innovatech-Solutions
  npm install
  ```

  **Run the development server:**

  ```bash
  npm run dev
  ```

- **Access the client site locally at:**  
  `http://localhost:5173`

## ✨ Key Features

- Responsive **Navbar** with animations & mobile toggle
- Engaging **Hero Section** with onload effects
- Interactive **Key Features** with hover states
- Styled **Success Stories** with responsive layout
- Highlighted **Pricing Plans** with Pro card animation
- Clean, responsive **Footer**
- Smooth **UI/UX enhancements** (buttons, hover, animations)

## ⚡ Problems I Faced

- **Navbar Fixed Position & Border**  
  Making the navbar fixed at the top while keeping its width aligned with large screens, and ensuring the border-bottom spans full width without breaking layout.

- **Loading Animation**  
  Adding a page reload animation — the challenge was avoiding the layout “break” that briefly appeared before the styles were applied.

- **Exit Animations**  
  Implementing smooth exit animations for components so they animate when leaving the view.

- **Scroll-based Animations**  
  Starting animations only when components come into the viewport, without performance issues.
